# layer-draw

画像を読み込むだけで「線画レイヤー」と「パーツ（塗り）レイヤー」に自動分解し、レイヤー単位で描き足し・塗り直しができるペイントアプリ。

- 仕様書: [docs/SPEC.md](docs/SPEC.md)
- 対応入力形式: PNG / JPEG / SVG

## 開発

Node.js 22 以上を想定しています。

```bash
npm install
```

```bash
npm run dev
```

```bash
npm test
```

```bash
npm run build
```

```bash
npm run bench
```

## 現在の実装範囲

- PNG / JPEG / SVG の読み込み（形式はファイル先頭のバイト列で判定）
- 自動分解（Web Worker で実行）: 線画抽出 → 領域分割（隙間閉じ・色による分割）→ 線下補完 → パーツのレイヤー化
- 分解パラメータの調整と再分解
- パーツのタップ選択（Shift/Ctrl/Cmd または「複数選択」で追加）、線を引いての分割、複数パーツの結合
- パーツ移動ブラシ（B）: なぞった所にある隣のパーツの画素を移動先パーツへ移して境界を直す。`[` / `]` でサイズ変更
- レイヤーパネル: 表示/非表示、不透明度、合成モード、クリッピング、並べ替え、削除、パーツの色変更
- 取り消し / やり直し（Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z、タッチでは 2 本指 / 3 本指タップ）
- キャンバスの拡大・縮小・回転・移動（ピンチ、Ctrl/Cmd+ホイール、Space+ドラッグ、手のひらツールなど。操作一覧は仕様書 7.2 節）

採用した手法・計測結果・残課題は仕様書 5.8 節を参照してください。
