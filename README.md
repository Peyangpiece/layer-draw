# layer-draw

画像を読み込むだけで「線画レイヤー」と「パーツ（塗り）レイヤー」に自動分解し、レイヤー単位で描き足し・塗り直しができるペイントアプリ。

- 仕様書: [docs/SPEC.md](docs/SPEC.md)
- 対応入力形式: PNG / JPEG / SVG、レイヤー付きの PSD / OpenRaster（.ora）

## Mac で使う（Dock に置く）

公開先: https://peyangpiece.github.io/layer-draw/ （GitHub Pages。下の「公開の準備」が済んでから使えます）

インストールしたアプリは独立したウィンドウで開き、一度開いた後はオフラインでも使えます。画像はすべて端末内で処理され、どこにも送信されません。

**Safari（macOS Sonoma 14 以降）**

1. Safari で上の URL を開く
2. メニューバーの「ファイル」→「Dock に追加…」→「追加」

**Chrome / Edge**

1. 上の URL を開く
2. アドレスバー右端のインストールのアイコン、またはメニューの「キャスト、保存、共有」→「ページをアプリとしてインストール…」（メニュー名はブラウザのバージョンにより異なります）
3. 起動中に Dock のアイコンを右クリック →「オプション」→「Dock に追加」

更新は自動です。オンラインで起動すると最新版になります。

## 現在の実装範囲

- PNG / JPEG / SVG の読み込み（形式はファイル先頭のバイト列で判定）
- レイヤー付きの PSD / OpenRaster の読み込み（レイヤー構成のまま開き、選んだレイヤーを自動分解できる）
- 自動分解（Web Worker で実行）: 線画抽出 → 領域分割（隙間閉じ・色による分割）→ 線下補完 → パーツのレイヤー化
- 分解パラメータの調整と再分解
- パーツのタップ選択（Shift/Ctrl/Cmd または「複数選択」で追加）、線を引いての分割、複数パーツの結合
- ペン（P）・消しゴム（E）で選択中のレイヤーに描く（筆圧・手ブレ補正・不透明度）、スポイト（I / Alt + クリック / 指で長押し）、新規レイヤー、透明度保護
- 保存（上部バーの「保存」/ Ctrl・⌘+S）: PSD（レイヤー付き。開き直して続きを編集できる）か PNG（1 枚の画像）。Chrome / Edge では保存先のフォルダを選び、以後 ⌘S で上書き。Safari では「ダウンロード」フォルダに保存される。保存先はダイアログ・通知・上部バーに表示
- パーツ移動ブラシ（B）: なぞった所にある隣のパーツの画素を移動先パーツへ移して境界を直す。`[` / `]` でサイズ変更
- レイヤーパネル: 表示/非表示、不透明度、合成モード、クリッピング、並べ替え、削除、パーツの色変更
- 取り消し / やり直し（Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z、タッチでは 2 本指 / 3 本指タップ）
- キャンバスの拡大・縮小・回転・移動（ピンチ、Ctrl/Cmd+ホイール、Space+ドラッグ、手のひらツールなど。操作一覧は仕様書 7.2 節）

採用した手法・計測結果・残課題は仕様書 5.8 節を参照してください。
